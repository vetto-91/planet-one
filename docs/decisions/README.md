# ADR — Architecture Decision Records (lite)

Registro delle decisioni tecniche significative. Un ADR per decisione, nome file: `NNNN-titolo-breve.md`.

## Template

```markdown
# ADR-NNNN: <titolo>

- Data: YYYY-MM-DD
- Stato: proposto | accettato | sostituito da ADR-XXXX
- Versione: vX.Y.Z.W

## Contesto
Perché siamo davanti a questa decisione.

## Decisione
Cosa abbiamo scelto.

## Conseguenze
Pro, contro, impatto sul codice e sulla roadmap.
```
